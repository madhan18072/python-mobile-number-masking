# Mobile Number Masking using Python

## Project Description

A simple Python project that masks a mobile number to protect sensitive information.

## Features

- Accepts mobile number from the user
- Validates that the input contains only digits
- Checks for exactly 10 digits
- Displays the first 5 digits
- Masks the remaining digits using '*'
- Handles invalid input

## Example

Input:
9876543210

Output:
98765*****

## Python Concepts Used

- Functions
- User Input
- Conditional Statements
- String Methods
- String Slicing
- isdigit()
- len()
- ljust()
- Return Values
